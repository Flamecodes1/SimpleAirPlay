# Privacy Policy — Simple AirPlay

**Last Updated:** May 19, 2026

## Data Collection

Simple AirPlay does **not** collect, store, or transmit any personal data, telemetry, analytics, or usage statistics.

## Network Usage

Simple AirPlay uses your **local network only** to receive AirPlay streams (audio, video, and screen mirroring) from Apple devices on the same network. No data is sent to external servers or the internet.

The following network protocols are used exclusively for local AirPlay communication:
- **mDNS** (UDP port 5353) — for device discovery on the local network
- **RTSP/AirPlay** (TCP ports 7000–7001, 7100) — for stream control
- **RTP** (UDP ports 6000–6001, 7011) — for media data

## Third-Party Components

Simple AirPlay uses the following open-source components:
- **UxPlay** (GPLv3) — AirPlay engine ([Source Code](https://github.com/FDH2/UxPlay))
- **GStreamer** (LGPL/GPL) — Multimedia framework ([Website](https://gstreamer.freedesktop.org/))

These components do not collect or transmit any user data.
